# Intercompany Fees and Dividends FAQ

Use this reference when the user asks how a Shanghai parent should charge a Hong Kong subsidiary, how profit can lawfully return, whether service fees or dividends are better, or what the main related-party sensitivities are.

## Core answer stance

Use this baseline:

`如果目标是既合法又容易解释，通常比起把全部利润都压在香港，采用“上海母公司收取合理服务费 + 香港税后利润再分红”的路径更自然。`

Keep the answer practical. Do not turn it into a formal tax opinion.

## FAQ 1. Shanghai did the R&D and operations. Can Hong Kong keep all the profit?

Default answer:

- Usually that is hard to justify if Shanghai performs substantial functions.
- Explain that if Shanghai undertakes development, operations, support, analytics, or management work, it usually needs reasonable compensation.
- Tie this back to transfer pricing and substance.

Useful wording:

`最容易被追问的点之一，就是上海做了大量实质工作，但利润大部分都沉在香港，而上海只承担成本或者只拿很少补偿。`

## FAQ 2. Should Shanghai charge service fees to Hong Kong?

Default answer:

- Usually yes, if Shanghai really provides services to Hong Kong.
- Explain that the arrangement should be supported by:
  - intercompany service agreement
  - defined service scope
  - pricing logic
  - settlement records

Useful wording:

`如果上海母公司实际在做研发、技术支持、运营支持或数据分析，通常应当由香港子公司按合理方式向上海支付服务费。`

## FAQ 3. Is dividend cleaner than royalties or aggressive IP charges?

Default answer:

- Usually yes from an explanation standpoint.
- Explain that dividends often look more natural than trying to move most profit through royalties, licensing, or other aggressive charges.
- Still remind the user that dividend remittance and PRC tax treatment need professional confirmation.

Useful wording:

`从解释逻辑上看，税后利润分红往往比一开始就设计很多复杂收费项更顺。`

## FAQ 4. What is the cleaner overall structure?

Default answer:

- Hong Kong subsidiary collects overseas revenue and bears overseas costs.
- Shanghai parent charges reasonable service fees for actual work performed.
- Remaining after-tax profit in Hong Kong is later distributed to Shanghai by dividend.

This should be the preferred practical narrative unless the facts point elsewhere.

## FAQ 5. What makes a service-fee arrangement more credible?

Tell the user to prepare:

- intercompany agreement
- service description
- pricing note or methodology
- billing or settlement records
- management approval records
- evidence of actual work done by Shanghai

Useful wording:

`不是写一份关联交易协议就够了，还要能说明上海到底做了什么、为什么这个收费方式是合理的。`

## FAQ 6. What are the main sensitivities?

Always mention:

- Hong Kong substance
- transfer pricing
- mismatch between contract party and value creation
- mismatch between collection entity and operating responsibility
- remittance, banking, and tax documentation

## FAQ 7. Can everything just be handled through dividends?

Default answer:

- Usually not ideal if Shanghai is actively providing major services.
- Explain that dividends are useful for residual profit return, but they do not replace reasonable compensation for real services already provided by Shanghai.

Useful wording:

`分红更像是剩余利润的回流路径，不太适合替代本来就应该存在的服务费安排。`

## FAQ 8. What tone should the answer use?

Prefer language like:

- `通常更稳的做法是`
- `从合规和解释角度看`
- `要结合实际职能、合同和资金流判断`
- `这类安排通常需要会计师或税务顾问进一步确认`

Avoid:

- absolute legality claims
- numerical pricing advice without facts
- instructions for hiding profit allocation motives
