# Answer Template

Use this template when the user wants a practical recommendation for a structure involving a Shanghai mainland parent, a Hong Kong subsidiary, overseas cloud or SaaS costs, Stripe income, or overseas product revenue.

## Default answer skeleton

Follow this order:

1. Short conclusion
2. Suggested entity positioning
3. Revenue and cost flow
4. Profit return path
5. Main risk points
6. Practical next steps

## Reusable wording

### 1. Short conclusion

Prefer wording like:

`这条路原则上可行，但关键不是设一个香港公司本身，而是业务、合同、收付款、税务处理和经营实质要能对得上。`

If the question is narrower, use:

`通常可以，但要把会计入账、税务处理、银行或外汇核查这几层分开看。`

### 2. Suggested entity positioning

When the facts fit, frame it like this:

- 香港子公司 = 海外业务经营主体
- 上海母公司 = 研发、运营支持、数据分析或共享服务中心

Useful wording:

`如果香港子公司同时承接 Stripe 收款、海外产品收入，以及腾讯云香港、Cloudflare 这类海外基础设施费用，这个定位会比“香港公司只是代付费壳公司”更容易讲通。`

### 3. Revenue and cost flow

Explain the desired consistency:

- overseas customer contracts or terms point to the Hong Kong entity
- Stripe merchant account belongs to the Hong Kong entity
- settlement bank account belongs to the Hong Kong entity
- Tencent Cloud Hong Kong and Cloudflare billing entity matches the Hong Kong entity
- refunds, customer support, and commercial responsibility line up with the same entity

Useful wording:

`最重要的是把合同流、资金流和责任承担方尽量做一致。`

### 4. Profit return path

Prefer this structure:

- Shanghai parent charges reasonable intercompany service fees for actual R&D or support work
- remaining after-tax profit in Hong Kong is later distributed as dividends to the Shanghai parent

Useful wording:

`如果目标是合法把利润回到上海母公司，通常比起一开始就把所有利润都压在香港，采用“合理服务费 + 剩余税后利润分红”的路径更自然。`

### 5. Main risk points

Always mention these:

- Hong Kong substance
- transfer pricing
- consistency of contract party, billing entity, and collection entity
- ODI, banking, and dividend remittance documentation

Useful wording:

`最容易出问题的不是结构图本身，而是香港公司没有实质、上海做了大量工作却没有合理补偿，或者合同和收款主体互相打架。`

### 6. Practical next steps

Offer a short checklist:

- define entity roles
- align website terms and contracts
- align Stripe and bank setup
- align Tencent Cloud Hong Kong and Cloudflare billing
- draft intercompany service agreement
- review transfer pricing
- confirm ODI, tax, and remittance handling with advisors

## Tone

- Be practical, not academic.
- Use `通常`, `一般`, `更稳的做法`, and `要结合事实判断`.
- Do not overstate certainty.
- Do not provide evasion playbooks.
