# Web 3D 探索解謎教育遊戲（中國大陸・滬教版首發）

## 產品概念
- Web 上運行的 3D 探索解謎遊戲，畫面偏寫實，涵蓋小學到高中全學科知識
- 玩家任務：解密闖關，畫面可隨時從 3D 切換為 2D（取決於解謎需要）
- 關卡由服務端全自動生成並推送，每次登錄可能收到新關卡開放通知
- 每關卡約 10 分鐘可通關，以若干知識點為主要內容，穿插生活常識及其他非學科知識
- AI 在闖關過程中自動判斷玩家知識水平；固定謎題之外的隨機謎題，難度略高於玩家當前水平

## 多角色 / 多地區架構（已確認）
- 玩家登錄時選擇課綱範圍；可同時建立多個角色，每個角色對應一個地區（台灣、大陸、新加坡、美國、英國等）
- 某地區角色未達一定進度前，其他地區角色不可使用，防止玩家淺嘗輒止
- 遊玩時玩家自報學段，AI 自動匹配對應課綱內容

## 首發範圍（已確認）
- 首發地區：中國大陸
- 首發課綱版本：滬教版（上海五四學制，小學 1-5 年級）
- 首發學段：小學全學段
- 首發學科：全學科（語文、數學、英語、自然、品德與社會、信息科技等）
- 跨版本解鎖：玩家在滬教版某年級考核達 80 分以上，可解鎖人教版或浙教版內容（內容後續補齊，架構先行支援）
- 跨地區解鎖門檻：具體數值待定

## 內容生成策略（已確認方向，待落地）
使用者要求「AI 來做內容、只定方向、上線當天全部內容到位」。落地時必須遵守：

1. **依據材料優先**：AI 不可憑空生成課綱內容，必須先取得滬教版課程標準（公開政策文件）作為生成依據。
   - 避免直接餵入教材原文掃描件——教材本身有出版社版權，直接拿來生成內容有版權風險；應使用課程標準/考綱等公開文件。
   - 若使用者沒有現成材料，需協助取得公開課程標準版本。
2. **內容模板先行**：統一的關卡內容結構，至少包含：知識點、情境/案例摘要、可見線索、隱藏線索、正確推理鏈、常見錯誤路徑、分級提示、結算反饋。
3. **批量生成**：依模板 × 課程標準知識點清單，用 AI 批量產出關卡草稿。
4. **校驗層不可省略**：
   - 數學/邏輯類：用規則或程式自動驗證答案正確性
   - 語文/知識類：至少人工抽查一輪，或用第二個 AI 模型交叉校對明顯錯誤
   - 面向未成年人的教育產品，內容錯誤的聲譽/合規風險大於延後上線的成本
5. 技術架構（角色系統、地區解鎖、課綱匹配邏輯）應一開始就按「小學全學段全學科、多地區多課綱版本」設計；內容庫可隨校驗進度逐批掛載，不必等其他地區/版本內容到齊才上線滬教版。

## 待確認事項（下次繼續時優先處理）
- 跨地區解鎖的具體進度門檻數值
- 滬教版課程標準材料來源（使用者提供 or 代為取得公開版本）
- 校驗層採「AI 交叉校對 + 抽查」還是要求人工逐條審核
- 3D/2D 引擎選型、雲端服務商、LLM API 供應商與預算
- 商業模式、目標時程
