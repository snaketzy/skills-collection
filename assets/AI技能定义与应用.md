**Assistant**

「Skill」（技能）是给 AI Agent 用的一种**可复用的能力封装**。简单说，就是把「一类任务怎么做」打包成一个模块，AI 遇到对应场景时加载它，就知道该按什么步骤、用什么工具去完成。

## 核心概念

一个 Skill 通常包含：
- **说明（description）**：告诉 AI「我是什么、什么时候该用我」
- **指令（prompt/流程）**：加载后展开的具体步骤、规则、最佳实践
- **配套资源**：脚本、模板、工具接口、参考资料

## 在 AI 上有什么用

| 作用 | 说明 |
|------|------|
| **补齐专业流程** | 通用大模型不一定会某个产品的特定 API 调用顺序，Skill 把「正确姿势」固化下来 |
| **按需加载，省上下文** | 只有触发了才加载，平时不占用词元（token），避免上下文浪费 |
| **保证一致性** | 同一类任务每次走同样流程，结果稳定、可复现 |
| **复用工具链** | 比如我这边 `lark-*` 系列技能，把飞书文档/表格/日历/审批等操作封装成标准动作 |

## 打个比方

- **模型** = 一个聪明但没上过岗的新人
- **Skill** = 岗位 SOP 手册 + 工具箱
- 新人平时凭常识干活，一旦遇到「处理飞书审批」这种专业活儿，就翻出对应手册照着做

## 实际例子（就在当前环境里）

我身上挂着 lark 插件的一堆技能，比如：
- `lark-sheets`：操作飞书电子表格
- `lark-doc`：读写飞书云文档
- `lark-calendar`：管理日程和会议室

当你让我「把这段数据整理成飞书表格」时，我不会瞎猜 API，而是先加载 `lark-sheets` 技能，按它规定的正确方式建表、写单元格。

**一句话总结**：Skill 是把领域知识和操作流程「模块化」，让 AI 在特定任务上从「泛泛而谈」变成「专业上手」。
